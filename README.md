# 3Dぐるぐる — 自作PCを、ひとつずつ。

ブラウザだけで遊べる、3D自作PC入門サイトです。登録・インストール不要。
ぐるぐる回して、バラして、実際にドラッグで組み立てながら、パーツの役割を学べます。

**デモ:** https://<ユーザー名>.github.io/<リポジトリ名>/

## 機能

- **図鑑**: 9つのパーツ(マザーボード、CPU、メモリ、SSD、クーラー、GPU、電源、ケーブル、ケース)を3Dで観察。分解表示つき
- **組み立て**: 11ステップをドラッグ&ドロップで体験
  - CPUの三角マークの向き合わせ
  - メモリはA2/B2スロット(デュアルチャネル)
  - グリス塗布、電源ケーブル3本の接続
  - 間違えると理由が表示される
- **相性チェック**: ソケット、DDR4/DDR5、クーラー対応、GPUの長さ、電源容量を判定
- **電源ON**: ファン回転、RGB、BIOS起動画面。クーラーを外して温度が上がる実験も
- **クイズ**: 5問と称号
- **PWA対応**: アプリとしてインストール可能、オフラインでも動作
- スマホ対応(タップ操作で組み立て)

## 操作方法

| 操作 | 内容 |
| --- | --- |
| ドラッグ / ホイール | 回転 / ズーム |
| `R` | 持っているCPUを回す |
| `E` | 分解表示 |
| `H` | ヒントのON/OFF |
| `M` | 音のON/OFF |
| `1`〜`4` | モード切り替え |

## 技術

- 単一HTMLファイル(`index.html`)に、CSS・JS・three.js r128 をすべて内包
- パーツは three.js でコードから生成(外部の3Dモデル・画像は不使用)
- Service Worker によるオフライン対応

## ファイル構成

```
index.html              本体
manifest.webmanifest    PWA設定
sw.js                   Service Worker
icons/                  アプリアイコン
```

## 公開方法(GitHub Pages)

1. このリポジトリの Settings → Pages
2. Source を `main` ブランチの `/ (root)` にして保存
3. 表示されたURLを開き、ブラウザの「インストール」からアプリ化
